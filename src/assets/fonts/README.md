Please place the Inter font files (.ttf) in this directory.
You can download them from Google Fonts: https://fonts.google.com/specimen/Inter

You will need the following files:
- Inter-Regular.ttf
- Inter-Medium.ttf
- Inter-SemiBold.ttf
- Inter-Bold.ttf

After adding the files, run `npx react-native-asset` to link them to the native projects.
